# Smart Signal — downloads

**Smart Signal** by **Your Boy D** is a now-playing overlay for OBS on Windows. It shows the song you are playing (cover, title, artist and timing) on your stream, with your own style, picture and choice of apps.

This repository only holds the installers and the automatic-update feed. The source code is private.

## Download

Get the latest `Smart-Signal-Setup-<version>-x64.exe` from [Releases](../../releases/latest). Smart Signal needs a licence key, which you receive when you buy it from Your Boy D.

Smart Signal updates itself. When a new version is ready, Windows shows "A new update is available" with an **Update** button.

## Is my download genuine?

Every release has a `.sig` file signed with Your Boy D's private update key. Installed copies check it before installing an update, and refuse anything that wasn't signed by Your Boy D. The installers are not yet signed with a Windows code-signing certificate, so Windows may show a SmartScreen warning the first time you install.
